Inspired by paper by Kwan, modified to be more modern. In particular, Detectron2 has been replaced with RTMPose, YOLO with GroundingDINO, and we have reworked head pose estimation to be compatible in cases where the person is wearing an AR headset.

1. Set up venv with Python3.9
2. Run pip install command for toml file in repo root
3. Install relevant dependencies in requirements.txt
